# Alke Wallet

Alke Wallet es una aplicación Front-End que simula el funcionamiento de una billetera digital.

## Funcionalidades

- Inicio de sesión.
- Visualización del saldo disponible.
- Depósitos de dinero.
- Retiros de dinero.
- Registro de contactos.
- Búsqueda de contactos.
- Transferencias de dinero.
- Historial de movimientos.
- Filtros por tipo de transacción.
- Cierre de sesión.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- LocalStorage
- SessionStorage
- Git
- GitHub
